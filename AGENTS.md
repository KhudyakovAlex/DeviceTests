# DeviceTests

Репозиторий для опытов и тестов устройств автоматизации зданий. Каждое устройство — отдельная папка с именем по order code производителя. Заметки, скрипты, дампы и результаты лежат только в папке этого устройства.

Ответы пользователю — кратко, по-русски. Факты по шине, адресам и регистрам брать из файлов папки или даташита. Если источника нет — так и сказать и спросить, не выдумывать карту устройства.

Сеть 220–240 В и выход реле — под напряжением. Схемы подключения нагрузки и измерения на сети давать только по явной просьбе.

## Устройства

### zc-pms-da-2sw-r

zencontrol PIR multi-sensor, 8 м. Папка: `zc-pms-da-2sw-r/`.

- Вариант `-da`: устройство DALI-2, ток шины < 2 мА, блок питания шины внешний.
- В опытах нужны только температура, влажность, eCO₂, eVOC и уровень звука.
- Всё известное по корпусу: `zc-pms-da-2sw-r/terminals.md`.
- Питание устройства: 220–240 В AC.

Новое устройство: новая папка по order code и короткая запись в этот раздел.
