# zc-pms-da-2sw-r

zencontrol, PIR и датчик качества воздуха, зона 8 м, встроенное реле и два входа выключателей. В опытах нужны температура, влажность, eCO₂, eVOC и уровень звука.

Источники: наклейка `IMG_20261013_104631.jpg`, мануал `zc-pms-iot_instruction-manual_web.pdf` (V1.1, 04/07/25, в нём и `-da`, и `-iot`), даташит https://zencontrol.com/wp-content/uploads/products/datasheets/zc-pms-da_Leaflet_Datasheet_w.pdf. Чего в них нет — в конце.

## Клеммы

По наклейке. Провод 0,5–2,5 мм², зачистка 6–8 мм. Две колонки, сверху вниз.

| Левая | Правая |
| --- | --- |
| DA | SW1 |
| DA | SW2 |
| L | L'out |
| N | N out |

- **DA, DA** — шина DALI. Полярность не важна. На чертеже даташита те же клеммы подписаны DA+ и DA−.
- **L, N** — питание датчика, 220–240 В ~ 50 Гц. Ток питания по мануалу < 0,1 А.
- **SW1, SW2** — входы выключателей. На схеме наклейки контакт между L и SW.
- **L'out, N out** — выход на нагрузку, 220–240 В ~ 50 Гц. Реле рвёт только фазу: L → L'out. N и N out соединены напрямую.

Клемм In и Out на этом корпусе нет. Это вариант `-r`. In / Out — у другого кода, `-vf`.

Ток контакта реле, три значка по 10 А на строке Output: ёмкостная, индуктивная и активная нагрузка. Пусковой ток по мануалу: 165 А / 20 мс и 492 А / 1,5 мс для светодиодов. Цепь реле защищать автоматом.

Шина DALI не SELV, её ведут как низковольтную сеть. Ток шины по даташиту < 2 мА. Блока питания шины на `-da` нет: у `-iot` он 16,5 В, 35 мА.

На наклейке написано «Wireless smart PIR sensor». В мануале строка Wireless — IEC 62386-104 по Thread — помечена только для `-iot`.

Температура на наклейке и в мануале: −10…55 °C. Корпус IP20.

## Что датчик отдаёт по DALI

Один control gear: реле, device type 7 (IEC 62386-208).

Один control device. Для `-2sw-r` в мануале 5 инстансов, режим ECD `0x00` / `0x80`:

| Инстанс | Тип |
| --- | --- |
| 0 | 3, присутствие (IEC 62386-303) |
| 1 | 4, освещённость (IEC 62386-304) |
| 2 | 0 |
| 3 | 1, кнопка (IEC 62386-301) |
| 4 | 1, кнопка (IEC 62386-301) |

Режимы `0x81`, `0x82`, `0x83` в таблице меняют только инстансы 3 и 4: кнопка (301) или абсолютный вход (302). Что означает тип 0 у инстанса 2, в мануале не сказано.

Автономные уставки из мануала: присутствие включает свет, простой 14 минут, затем свет на 1 %, ещё через 1 минуту без движения свет гаснет. SW1 — диммер, SW2 — цвет. Автономный режим снимается после адресации ECD/ECG по IEC 62386-104 или если режим ECD выставлен в 0.

## Диапазоны с даташита `-da`

| Величина | Диапазон |
| --- | --- |
| Температура | −20…85 °C (±1 °C); −10…40 °C (±0,5 °C) |
| Влажность | 0…100 % RH (±3 %) |
| eCO₂ | 0…60 000 ppm |
| eVOC | 0…60 000 ppb |
| Звук | 35…100 дБА Leq (±2 дБА) |
| Освещённость | 0…10 000 лк (±5 %) |

В списке устройств даташита климатические входы названы так: IEC 62386-3XX, generic input, 4 штуки. Плюс реле 208, движение 303, свет 304, ИК-вход 302, кнопки 301 ×2. В перечне стандартов даташита части 306 нет.

## Чего в документах нет

Номеров инстансов температуры, влажности, eCO₂, eVOC и звука нет. Формулы перевода сырого значения в единицы нет. В таблице инстансов мануала этих пяти величин нет. Статья zencontrol про датчики 306 описывает их контроллер и не привязана к этому коду. Снять показания качества воздуха по опубликованным документам нельзя: карту можно получить только опросом этого корпуса по шине.
